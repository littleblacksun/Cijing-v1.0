# 「词境」行测逻辑填空学习与智能刷题 App — N 阶段开发任务书

> **项目定位**：面向公务员/事业单位《行测 · 言语理解 · 逻辑填空》的移动端离线学习 + AI 智能出题训练工具（Android APK）。
> **核心理念**：以「语境 + 语素 + 对比辨析」替代死记硬背词典释义，结合 LLM 动态组卷与本地题库闭环复习，实现随时随地精准提分。

---

## 一、产品核心设计方案（借鉴主流学习 App 的方法论升级）

### 1. 成语「六维深度理解」学习法（参考墨墨背单词 / Anki）
行测逻辑填空不考背诵辞典原文，而是考**语境契合度与辨析能力**。每条成语卡片按 6 个维度结构化呈现：
1. **核心词义（一语破的）**：用 15~25 字直击考试高频义项，标出「易望文生义」预警角标。
2. **核心语素拆解**：高亮决定含义的关键字（如「首当其**冲**」标亮“冲=要冲/首当面对”，破除“冲锋”误解）。
3. **行测四维属性标签**：
   - 感情色彩：`褒义` / `贬义` / `中性`
   - 语义轻重：`较轻` / `适中` / `较重`
   - 适用对象（如：仅用于人 / 用于文章 / 用于自然景观 / 谦辞敬辞）
   - 常见语法功能与搭配（如：常作谓语/定语、常与否定词连用等）
4. **真题感语境例句（支持遮罩自测）**：例句中将成语挖空或模糊遮罩，点击翻卡揭晓答案，形成「主动回忆」。
5. **高频误用雷区**：一句话指出行测命题人最常设的坑（如褒贬误用、对象错配、重复累赘）。
6. **掌握度分级与间隔复习**：底部提供 `陌生` / `模糊` / `熟悉` / `掌握` 四个轻量反馈按钮，自动影响首页复习队列与 AI 出题选词权重。

### 2. 易混成语「四重对比理解」机制（行测提分核心）
将 2~4 个高频易混词打包为一个**辨析对比组**（如 `不以为然 vs 不以为意`、`休戚与共 vs 休戚相关 vs 息息相关`），提供 4 种强化辨析视图：
1. **异字彩色标亮**：自动/结构化高亮对比词中的不同字素，直击词义分叉点。
2. **一屏差异矩阵**：横向对比「核心侧重 / 感情色彩 / 语义轻重 / 适用对象」，一眼看清区别。
3. **最小对立语境（同句对比）**：展示高度相似的句子，标明「此空选 A 不选 B」的语境关键词。
4. **闪电二选一微练**：浏览完对比组后，点击「立即小测」弹出 1~2 道 5 秒快速选词题，趁热巩固记忆。

### 3. LLM 智能出题 + 本地题库权重闭环（参考粉笔刷题体验）
- **灵活选词**：支持从词库「手动多选成语」「按易混组选择」「一键抽陌生/模糊词」「随机抽词」作为本次出题的靶向词单。
- **题量与本地旧题权重抽题**：
  - 题量选项：`5 / 10 / 15 / 20` 题。
  - **默认 20% 本地题库抽题比例**（`5→1`、`10→2`、`15→3`、`20→4`），在「设置」中支持自由调整（`0% ~ 50%`）。
  - **智能抽取策略**：优先从本地题库中抽取「与本次选中成语相关」→「曾答错的」→「最久未复习的」题目；若本地题库可用题量不足目标数，按实际可用数抽取，剩余题量自动由 LLM 补足并提示用户。
- **双答题模式**：
  - **即时解析模式（学习优先）**：点击 A/B/C/D 后立即显示对错、高亮题干语境关键词、展开正确答案精析与其余三项逐项排除理由，支持单题一键「收入本地题库」。
  - **交卷解析模式（实战优先）**：沉浸式连续答题，配备顶部进度条、答题卡自由跳转、**干扰项划线排除**（行测实用手感）与计时；交卷后展示成绩报告、正误格阵，支持逐题复盘与批量选择收入本地题库。

## 二、技术架构与协作工作流

### 1. 技术选型
- **前端 UI 框架**：React 18 + TypeScript + Vite + Tailwind CSS
- **路由与状态管理**：React Router v6 + Zustand
- **本地离线存储**：IndexedDB（Dexie.js），支持大容量语库检索、学习记录、本地题库与 JSON 一键导入导出备份
- **移动端封装与打包**：Capacitor 6（原生 Android WebView + `CapacitorHttp` 原生网络请求，彻底规避手机端直连 LLM API 的 CORS 跨域问题）
- **视觉风格**：**清新护眼效率风**（参考粉笔 / 墨墨背单词：柔和灰白底 `#F5F7FA` + 纯白卡片 `#FFFFFF` + 护眼青蓝主色 `#2563EB` / `#0EA5E9` + 语义绿 `#10B981` / 珊瑚红 `#EF4444` / 琥珀橙 `#F59E0B`）


## 四、六阶段详细任务书（N = 6）

### 阶段 1：工程脚手架、设计系统与数据规范（Foundation）
**阶段目标**：搭建可即时浏览器预览的 React + Vite + Tailwind + Capacitor 项目骨架，确立全局设计 Token 与离线数据库 Schema，打通 `语库/` 自动加载管道。
- **核心任务**：
  1. 初始化 Vite + React + TypeScript + Tailwind CSS 工程，配置移动端视口（390×844 标准设计基准 + 响应式适配 + 顶部/底部安全区 CSS 变量）。
  2. 建立全局设计系统（颜色变量、字号阶梯、圆角/阴影规范、通用基础组件：TopBar、BottomNav、Tag、Card、Button、EmptyState）。
  3. 设计 Dexie.js 本地数据库表结构：`idioms`（成语）、`confusion_groups`（易混组）、`study_progress`（学习进度与熟练度）、`local_questions`（本地题库）、`quiz_sessions`（答题记录）、`app_settings`（API 与权重配置）。
  4. 编写 `语库/` 目录数据加载与校验脚本，支持将 `语库/*.json` 打包为内置初始词库，并支持 App 内热更新/导入。
- **本阶段涉及 UI（基础框架）**：
  - `UI-00` 全局设计规范与组件风格卡（含 4-Tab 底部导航壳、顶部导航栏、色板与标签规范）。
- **验收标准**：`npm run dev` 启动正常，4 个 Tab 可流畅切换，示例语库成功写入 IndexedDB。

### 阶段 2：成语深度理解与易混对比模块（Core Learning）
**阶段目标**：完成核心背词与辨析体验，让用户随时打开软件就能高效理解单个成语并区分易混词。
- **核心任务**：
  1. **首页学习看板**：统计今日已学/待复习词数、总体掌握率、快速入口与高频易混组推荐卡片。
  2. **词库浏览与多维检索**：支持「成语列表」「易混对比组」双 Tab；按拼音/汉字实时搜索；按掌握度（陌生/模糊/熟悉/掌握）、感情色彩、易望文生义标签筛选；支持开启「多选模式」直接勾选成语跳转 AI 出题。
  3. **成语深度理解卡**：展示六维结构化内容（释义、关键语素高亮、四维标签、误用提示、遮罩自测例句、关联易混组跳转），支持左右滑切词与掌握度打分。
  4. **易混成语对比页**：一屏展示同组 2~4 个成语的异字高亮、核心差异对照表、同句换词正误解析。
  5. **闪电微练弹窗**：易混组底部一键触发 1~2 道快速二选一填空巩固题。
- **本阶段涉及 UI（5 个核心页面）**：
  - `UI-01` 首页学习看板（Home）
  - `UI-02` 词库双视图页（成语列表 & 易混组列表 + 搜索筛选 + 多选浮条）
  - `UI-03` 成语深度理解卡 / 闪卡页（含遮罩自测与底部 4 级掌握度反馈栏）
  - `UI-04` 易混成语对比辨析页（异字高亮 + 差异对照表 + 语境对比）
  - `UI-05` 易混闪电微练弹窗/浮层（二选一快测 + 即时反馈）
- **验收标准**：完全离线可用；任意成语可查看六维解析并更新掌握度；易混组对比清晰直观、不产生横向排版错乱。

### 阶段 3：LLM 智能出题引擎与组卷配置（AI Quiz Generator）
**阶段目标**：打通通用 OpenAI 兼容接口，实现基于指定成语清单 + 本地题库配比的高质量行测逻辑填空组卷。
- **核心任务**：
  1. **刷题组卷配置页**：
     - 选择出题成语来源（手动挑选 / 从词库带入 / 选择易混组 / 陌生词优先 / 随机抽词）。
     - 选择题量：`5 / 10 / 15 / 20` 题。
     - 选择答题模式：`即时解析模式` / `交卷解析模式`。
     - 实时显示**题源构成预览条**（例：共 15 题 = 3 道本地题库旧题 [20%] + 12 道 AI 实时新题）。
  2. **OpenAI 兼容 API 客户端**：封装标准 `/chat/completions` 调用（Web 预览走 fetch，Android 打包自动走 CapacitorHttp 防跨域），支持自定义 Base URL、API Key、Model。
  3. **行测出题 Prompt 工程与 JSON 强校验**：
     - 约束生成贴近国考/省考风格的单空/两空/三空逻辑填空题，明确考察指定成语及强干扰项。
     - 强制返回结构化 JSON（题干、选项 A/B/C/D、正确答案、语境关键词数组、总解析、A/B/C/D 逐项解析、关联成语数组）。
     - 处理 Markdown 代码块剥离、JSON 修复、题量不足自动补抽或单次重试、长请求防超时（支持分批生成如 15/20 题分 2 批防截断）。
- **本阶段涉及 UI（3 个核心页面）**：
  - `UI-06` 刷题组卷配置页（Practice 主页）
  - `UI-07` 选词抽屉/全屏选词页（支持搜索、标签筛选、已选预览）
  - `UI-08` AI 出题生成加载与容错页（分步进度指示、取消/重试提示）
- **验收标准**：填写真实 API Key 后，能稳定生成 5/10/15/20 道合法 JSON 逻辑填空题，异常（断网/Key 错误/格式异常）有清晰可读提示。

### 阶段 4：双模式沉浸式答题与复盘系统（Quiz & Review）
**阶段目标**：打造媲美粉笔 App 的顺滑手机刷题手感，完整实现两种答题模式及题目入库筛选。
- **核心任务**：
  1. **通用答题引擎**：
     - 顶部进度条、题源徽章（`AI 新题` / `本地旧题`）、模式标签、计时器与答题卡入口。
     - 题干高亮填空下划线，A/B/C/D 选项支持点击作答与**长按/右侧按钮划线排除**（交卷模式下的行测提速技巧）。
  2. **即时解析模式**：
     - 选中选项后立即锁定当前题，绿/红反馈正误，平滑展开解析卡片（语境线索 + 逐项解析 + 涉及成语可点击查看卡片）。
     - 解析区自带显著的「收入本地题库 / 已在题库」开关按钮。
  3. **交卷解析模式**：
     - 答题过程不泄题，可自由上下题切换或通过答题卡跳转未答题，答完点击「交卷查看解析」。
     - 进入**成绩报告页**（正确率环形图、用时、对错编号矩阵、关联薄弱成语提示），并可进入**整卷解析复盘页**（支持“只看错题”过滤 + 逐题/一键全选收入本地题库）。
- **本阶段涉及 UI（3 个核心页面）**：
  - `UI-09` 沉浸式答题页（含「作答态」「即时解析展开态」「答题卡底部抽屉」）
  - `UI-10` 交卷成绩结算报告页（统计概览 + 题号正误矩阵 + 快捷操作）
  - `UI-11` 整卷解析复盘页（支持“全部/仅看错题”切换 + 批量/单题入库开关）
- **验收标准**：两种模式切换准确无串状态；单题/批量入库立即持久化到本地题库，且自动去重。

### 阶段 5：本地题库闭环、权重抽题与设置中心（Local Bank & Settings）
**阶段目标**：完善本地题库的增删查练与权重抽题算法，完成 API 配置与数据备份能力。
- **核心任务**：
  1. **权重混抽算法实现**：
     - 读取设置中的抽题比例 `ratio`（默认 `20%`），计算 `localTarget = Math.round(total * ratio)`（在 `ratio > 0` 且有可用本地题时至少抽 1 题；默认 20% 时精确对应 `5→1, 10→2, 15→3, 20→4`）。
     - 抽题优先级：命中本次选定成语的本地题 > 历史错题 > 最久未刷的题；不足部分自动转给 LLM 补足。
     - 混排顺序：将本地旧题与 AI 新题随机打散，避免固定出现在开头或结尾。
  2. **本地题库管理页**：
     - 展示已收藏题目总数、错题数、来源统计；支持按题干/成语关键词搜索、筛选「仅错题」。
     - 点击可展开完整题目与解析，支持「移除出题库」或直接发起「本地题库专项复习」。
  3. **设置与 LLM API 配置页**：
     - OpenAI 兼容配置（Base URL、API Key 显隐切换、Model 名称、温度、出题难度预设：国考/省考/基础巩固、一键测试连通性）。
     - 本地题库抽题比例滑块（`0% ~ 50%`，步长 5%，实时显示 5/10/15/20 题对应的抽取数预览）。
     - 语库与个人数据管理（导出 JSON 备份、导入恢复本地题库与学习记录、手动导入新语库 JSON）。
- **本阶段涉及 UI（3 个核心页面）**：
  - `UI-12` 本地题库管理页（筛选搜索 + 题目卡片列表 + 详情/错题专练入口）
  - `UI-13` 设置中心页（抽题权重可视化滑块、默认模式、字号、数据导入导出）
  - `UI-14` LLM API 配置与连通性测试页（表单、快捷格式提示、测试结果反馈条）
- **验收标准**：调整比例后组卷题源数量精确联动；API 测试能准确返回成功/错误原因；导出备份后清空重导数据完整恢复。

### 阶段 6：Capacitor Android 封装、体验打磨与 APK 导出（Build & Release）
**阶段目标**：将 Web 应用封装为体验扎实的原生 Android App，并生成可直接在手机安装的 APK。
- **核心任务**：
  1. 初始化 Capacitor Android 平台（`npx cap add android`），配置包名、应用名「词境」、App 图标与启动页（Splash Screen）。
  2. 移动端原生细节适配：
     - 状态栏颜色与浅色图标适配（`StatusBar`）、底部导航栏手势区安全距离（`env(safe-area-inset-bottom)`）。
     - 安卓物理返回键处理（弹窗关闭 → 返回上一页 → 答题中二次确认防误退 → 首页双击退出）。
     - `AndroidManifest.xml` 网络权限与 `usesCleartextTraffic`（兼容自建 HTTP 中转 API）。
  3. 全链路端到端验证（离线背词、易混对比、真 API 生成 5/10/15/20 题、双模式作答、入库、权重混抽）。
  4. 配置 Android SDK 命令行构建环境与签名密钥，通过 Gradle 构建导出 `app-release.apk` 到输出目录供用户手机安装。
- **验收标准**：APK 在真机上可正常安装、离线打开词库流畅、联网调用 LLM 出题正常无 CORS 报错、横竖屏与返回键交互无异常。
