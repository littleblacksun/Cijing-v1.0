## 一、核心原则与边界（Guardrails）

1. **视觉优先、可交互静态 UI 演示**：本任务包专注**像素级 UI 还原 + 纯前端交互态演示**（如切换题量 5/10/15/20 实时更新配比条、切换即时/交卷模式、勾选成语、答题点选与划线排除、弹出答题卡抽屉、切换「收入本地题库」开关、拖动权重滑块实时更新 `5→1/10→2/15→3/20→4`、切换 API Key 明暗文等）。
